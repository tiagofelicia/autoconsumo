## Sobre (histórico)

Ferramenta para avaliar a viabilidade financeira de sistemas fotovoltaicos com autoconsumo, em
Streamlit + Pandas + Folium + FPDF2. Usava perfis de carga E-Redes (15 min), produção solar via
PVGIS, modelava baterias e projetava payback a 25 anos contemplando inflação energética e
degradação dos painéis.
